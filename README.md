# U.S. Flight Tracker Placefiles

AquaCeroWx / GRLevelX live aircraft placefiles served by the Cloudflare Worker and Cloudflare D1.

## Primary live placefiles

Use the Cloudflare Worker URLs, not the static GitHub raw file, for live data:

- Full U.S. coverage: `https://flighttracker.mitchellgeissler.workers.dev/flighttracker.txt`
- `/pacific.txt`
- `/southwest.txt`
- `/mountain.txt`
- `/central.txt`
- `/southeast.txt`
- `/northeast.txt`

Every Worker placefile uses `RefreshSeconds: 15` and `Cache-Control: no-store`. The placefile reload interval is separate from the upstream aircraft collection interval.

## Live data collection

- Primary source: FlyItalyADSB, authenticated with the `FLYITALYADSB_API_KEY` Worker secret.
- The collector covers 49 areas: 38 lower-48 coverage points plus Alaska, Hawaii and Puerto Rico.
- It reads `X-FIA-Plan` and `X-FIA-Limit-Per-Min` from the API and adapts the collection batch and radius to the key's plan.
- Free plan: up to 30 requests/minute and 500-km radius. The Worker uses 27 calls per minute, so the 49-area sweep takes about 2 minutes.
- Starter plan: up to 60 requests/minute and 1,000-km radius. The Worker can collect all 49 areas in one scheduled minute.
- Pro/Fleet plans have higher limits and whole-world access; the current Worker still uses the 49-area grid.
- Collection is protected by an expiring D1 lock to prevent overlapping scheduled sweeps. Individual region failures are recorded while successful regions are saved.
- ADSB.fi collection is disabled because its public endpoint returned Cloudflare HTTP 403 responses from the Worker egress. Its health endpoint remains available for diagnostics only.
- FlyItalyADSB API responses are fresh network observations; the Worker placefile is re-rendered on every request.

## Health and diagnostics

- `/health` reports the active FlyItaly plan, requests/minute, last successful collection, number of areas updated, per-area update ages, errors and estimated full-sweep time.
- `/adsbfi-health` reports the old ADSB.fi cache and marks that collector disabled.
- `/adsbfi-probe` can verify whether ADSB.fi access is still blocked from the Worker.

## Helicopter and business-jet symbols

- Helicopters use icon file 2: `assets/helicopter-map-icon-96.png`, 96×96, centered anchor 48×48.
- Business jets use icon file 7: `assets/business-jet-purple.png`.
- The placefile `Icon` statement uses the correct order: icon-file number, then icon number.
- Classification checks ICAO type designators, aircraft descriptions and available registry enrichment. Unknown or incomplete type data remains General Aviation rather than being silently dropped.

## Legacy GitHub raw placefile

The raw GitHub `flighttracker.txt` is a backup generated by GitHub Actions on a five-minute schedule. Its FlyItalyADSB collection is separate from the Cloudflare Worker and is not the sub-60-second primary feed. Use the Cloudflare Worker URLs above.

## Data limitations

Aircraft only appear when the provider has a usable ADS-B/MLAT position and reports the aircraft. No public aggregator can guarantee every aircraft or continuous coverage. This is an awareness/visualization feed, not a certified surveillance system and must not be used for dispatch, separation or other safety-critical decisions.
