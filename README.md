# U.S. Flight Tracker Placefiles

AquaCeroWx / GRLevelX live aircraft placefiles served by the Cloudflare Worker and Cloudflare D1.

## Live regional placefiles

The Worker serves six regional placefiles, rendered from the latest stored ADS-B snapshots:

- `/pacific.txt`
- `/southwest.txt`
- `/mountain.txt`
- `/central.txt`
- `/southeast.txt`
- `/northeast.txt`

Each placefile is generated when requested and advertises `Refresh: 1`. The Worker response uses `Cache-Control: no-store`.

## Data refresh cadence

- Cloudflare Cron is configured for every minute (`* * * * *`).
- Each scheduled run now attempts all 38 lower-48 adsb.fi coverage points, not only a rotating batch of six.
- Requests are spaced approximately 1.05 seconds apart to respect the public feed's one-request-per-second guidance.
- Successful regional responses are written to D1 even if an individual region fails. One failed region no longer discards the other successful updates.
- The regional placefiles merge the freshest positions from adsb.fi and FlyItalyADSB, deduplicate aircraft by ICAO24, and render the most recent available position.
- FlyItalyADSB remains a secondary feed, collected in rotating batches; its full nationwide sweep is slower due to the provider's request quota.

## Health and diagnostics

- `/health` reports both feeds' last attempt, last success, errors, and cached region counts.
- `/adsbfi-health` reports the adsb.fi sweep status, per-region update ages, and failures.
- A successful full-grid adsb.fi collection should refresh all 38 regions during each minute's scheduled run. Cloudflare Cron is minute-granularity and is not a hard real-time guarantee; feed outages, slow responses, or platform delays can still cause a late cycle.

## Legacy GitHub placefile

The raw GitHub `flighttracker.txt` is a separate legacy/backup output generated by GitHub Actions on a five-minute schedule. Its 59-point FlyItalyADSB scan is quota-limited and is not the sub-60-second regional service. Use the six Cloudflare regional placefiles for the minute-refreshing feed.

## Data and display

Aircraft visibility depends on ADS-B/MLAT receiver coverage and provider availability. The tracker is not a certified surveillance feed and must not be used for dispatch or safety-critical decisions.
